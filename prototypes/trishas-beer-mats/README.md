# Trisha’s beer-mat prototype

Standalone playtest, separate from the main story. Lea sets the challenge; Jack keeps count.

Serve the repository over HTTP and open `prototypes/trishas-beer-mats/`. Uses the existing vendored Three.js library. Tap Flick or press Space, then catch the turning stack with a second press. Each flip varies in speed.

The room is built from simple 3D geometry, procedural textures and lighting. The six framed pub and jazz images are generated fictional photographs; see PHOTO-ASSETS.md. Character names and dialogue remain provisional.

Personal best is saved locally in the browser. No main-game passages or saves are modified.
